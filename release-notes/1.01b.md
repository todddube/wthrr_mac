# wthrr 1.01b — What's New

## Settings & UI
- **Settings footer on every tab** — About, Onboarding, and What's New buttons now appear at the bottom of all four settings panels (Appearance, Environment, Presets, Behavior), with app version and GitHub link for quick reference
- **App version in popover** — version, build number, and GitHub link shown in the menu bar popover footer for consistency

## Splash Screen
- **Don't show on startup** — new checkbox on the splash screen lets you disable the startup splash; preference is remembered across launches
- **Startup splash fix** — fixed splash screen buttons not rendering until mouse hover on launch (window now activates correctly on all macOS versions)

## Performance
- **Adaptive Quality** — new Behavior setting that automatically halves particle count when CPU exceeds a configurable threshold (default 70%) and drops to 30 fps when battery is below a threshold (default 20%) while unplugged; live status indicator shows current state

## Scripts
- **DMG background** — installer window now features a weather showcase background: aurora gradient, snowflakes, rain streaks, lightning bolt, and fog wisps
- **Build script improvements** — `--bg-only` and `--dmg-only` flags for faster iteration; shows build number in preflight output
