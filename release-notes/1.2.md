# wthrr 1.2 — Retro 8-bit mode

Every weather scene can now be drawn as chunky 8-bit pixel art with one switch. This release also adds a one-command build-and-install script for people building from source.

**Source:** [github.com/todddube/wthrr_mac](https://github.com/todddube/wthrr_mac)

---

## Retro 8-bit mode

Turn on **Retro 8-bit** in the menu bar popover, or in Settings → Appearance → Style. All seven weather types redraw as pixel art using a fixed, console-style palette.

- **Snow** — three snowflake sprites that match the dot, star, and dendrite crystals, and stepped drifts with a white cap.
- **Rain and Thunderstorm** — streaks that tilt with the wind in a classic stair-step, droplets that hop out of each splash, tapered puddles, a blocky lightning bolt, and a screen flash that fades in steps.
- **Clear Skies** — a pixel sun with rotating dashed rays that turns orange at golden hour, and at night a cratered moon with twinkling four-point stars. Motes blink.
- **Aurora** — curtains of two-pixel stripes with a magenta fringe and a dithered bottom edge, over a starfield.
- **Fog** — broken, drifting scanlines that thin out toward the edges of each fog bank.
- **AI Storm** — alien ships become animated space invaders. Glitch fragments, corruption noise, and data bolts are all pixel-based, and still use your chosen neon palette.
- **Pixel Size** — choose Fine, Classic, Chunky, or Huge pixels (3 / 4 / 6 / 8 pt).

Retro mode only changes how the scene is drawn. The same particles, clouds, and lightning are simulated either way, so you can switch styles at any moment without the scene resetting. Live Weather, presets, and every slider keep working in retro mode.

It costs about the same as the regular style. Each colour layer is filled in one draw call, and each cloud's pixel shape is computed once and reused.

## Settings

- The Appearance tab now scrolls, which makes room for the new Style section.

## Building from source

- **`scripts/install.sh`** runs the unit tests, builds a Release copy, signs it, quits the running copy, replaces `/Applications/wthrr.app`, and relaunches it. Options: `--skip-tests`, `--no-launch`, `--dest DIR`. It finds Xcode on its own even when `xcode-select` points at the Command Line Tools.
- If you use Claude Code, the project's **app-builder** agent runs the same script and summarises any failing tests or compile errors.

## Under the hood

- Bird flight paths are computed in one place, so regular and retro birds fly identical routes.
- 17 new unit tests cover pixel snapping, line drawing in every direction, sprite placement and flipping, and how fades are stepped.
